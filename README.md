# RClauncher (Step 1-2)

右クリック2回で起動する常駐ランチャー。
- デスクトップの何もない場所でダブルクリック → フォルダ一覧 (config.toml の [[folders]]) → Explorerで開く
- アプリ画面内で右クリック2回 → クリップボード履歴 (最大200件) → 選択して貼り付け
- デスクトップ上の右クリック2回は無効 (通常の右クリックメニューのみ)
- タスクトレイ右クリック → 設定再読み込み / 終了

## ビルド (Windows)
1. Rust (rustup) と Visual Studio Build Tools (C++) をインストール
2. このフォルダで `cargo build --release`
3. `target\release\rclauncher.exe` を起動 (初回に config.toml が exe の隣に生成されます)

## 既知の制限
- 管理者権限で動くアプリ上では、フックが効かない (RClauncherも管理者で起動すれば可)
- テキスト以外 (画像・ファイル) は履歴に入らない
- サブフォルダはメニューにマウスを乗せた時に初めて読み込む (遅延展開)。応答しないネットワークドライブは、そのフォルダを開く時に待たされる

## クリップボード履歴ファイル
- exe と同じ場所の `clipboard\history.txt` (起動時に無ければ作成)
- UTF-8、1行=1件、古い順(末尾が最新)。`\` は `\\`、改行は `\n`、復帰は `\r` で保存
- **平文で保存されます**。パスワード等のコピーに注意 (パスワードマネージャが「除外」指定したデータは保存しません)
- メニュー最下段の「履歴クリア」で history.txt を空にします
- メニュー表示は1行・10文字まで。超える場合は先頭10文字+`...`

## フォルダ一覧の操作
- フォルダ名をクリック → そのフォルダを Explorer で開く (サブフォルダの一覧は、マウスを乗せると展開)
- 「このフォルダを開く」 → キーボード操作用 (Enter でも開ける)

## フォルダ履歴
- メニューから開いたフォルダを `folder_history.txt` (exe と同じ場所、1行1パス、新しい順) に記録
- フォルダ一覧の先頭の「履歴」サブメニューに表示。最下段の「履歴クリア」で全削除
- 履歴から選んだフォルダが存在しない場合は、履歴から外してメッセージを表示

## トレイメニュー / 設定
- 設定… : 登録フォルダの追加・削除・並べ替え、各種数値、自動起動をGUIで編集 (保存時 config.toml のコメントは保持)
- 設定ファイル/フォルダを開く、設定を再読み込み
- config.toml を直接編集して保存すると、2秒以内に自動で再読み込み
- Windows 起動時に自動起動 : HKCU\Software\Microsoft\Windows\CurrentVersion\Run に登録

## アプリ内フォルダ一覧の右クリックメニュー
- フォルダ一覧のフォルダ項目を右クリック → フォルダ一覧がいったん閉じ、Explorer と同じ右クリックメニューを表示 (Shift+右クリックで拡張メニュー)
- メニューを選ばずにEscキーで閉じると、フォルダ一覧が同じ位置に開き直す
- エラー発生時は、exeファイルと同じ場所の `rclauncher.log` に記録
- Explorer のメニューには他社のシェル拡張が読み込まれる。不安定になる場合は main.rs の `shellmenu::` の3か所を外すと無効化できる
